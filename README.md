# Proyek

Pemrograman Mobile

## Deskripsi

Aplikasi latihan untuk pembelajaran Pemrograman Mobile. Aplikasi ini direncanakan untuk membantu pengguna mengetahui aktivitas transaksi dengan lebih mudah dan praktis melalui smartphone.

## Tujuan

Proyek ini bertujuan untuk mengembangkan aplikasi mobile yang membantu pengguna mengetahui aktivitas transaksi dengan lebih mudah dan praktis melalui smartphone.

## Rencana Fitur

1. **Transaksi Masuk**

   Fitur untuk memudahkan pengguna melihat dan mencari detail transaksi uang yang masuk ke rekening.

2. **Transaksi Keluar**

   Fitur untuk memudahkan pengguna melihat detail transaksi uang yang keluar dari rekening.

3. **Notifikasi Transaksi Real-time**

   Fitur untuk memberikan notifikasi secara lebih cepat ketika terdapat transaksi uang masuk atau keluar.

## Cara Menjalankan

Pastikan Flutter sudah terpasang dan dapat digunakan. Jalankan perintah berikut pada terminal di folder proyek:

```bash
flutter pub get
flutter run
